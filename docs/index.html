01 / WHAT IS A SYSTEM?

A relationship between input and output.

A physical system, or plant, responds to an input over time. A motor turns voltage into motion; an RLC circuit turns applied voltage into capacitor voltage. Its dynamics determine how quickly the output moves, whether it oscillates, and where it settles.

02 / THE TRANSFER FUNCTION

A compact model of the dynamics.

For a linear, time-invariant system starting from rest, G(s) = Y(s) / U(s) relates input and output in the Laplace domain. The model below describes a stable second-order plant with gain K, natural frequency ωₙ, damping ratio ζ, and an optional delay L. These parameters determine its response to an input.

SECOND-ORDER PLANT + DELAYG(s) = Kωₙ²s² + 2ζωₙs + ωₙ² e−Ls

KSets the eventual output for a unit input.

ωₙSets a characteristic speed of response.

ζShapes damping and oscillation.

LDelays when the response begins.

03 / OPEN LOOP

Let the plant respond on its own.

A unit step changes the input from 0 to 1. Without feedback, the input stays at 1 regardless of what the output does. For this plant family, the output eventually approaches K; it does not automatically track a desired output of 1.

04 / CLOSE THE LOOP

Measure. Compare. Correct.

SAME PLANT / ADJUSTABLE CONTROLLER

Choose a desired output, the setpoint r(t). Negative feedback compares it with the actual output: e(t) = r(t) − y(t). The ideal PID controller C(s) = Kp + Ki/s + Kd·s uses three actions to turn that error into a changing plant input. Together, the three terms determine the input applied through a single feedback loop.

P / PRESENT

Proportional

Acts on the error now. A larger Kp reacts more strongly, but can increase oscillation.

Kp × e(t)
I / PAST

Integral

Accumulates error over time. It can remove persistent offset in a stable loop, but too much can cause overshoot.

Ki × ∫ e(t) dt
D / RATE OF CHANGE

Derivative

Acts on how fast the error changes. It can add damping; ideal differentiation is sensitive to noise and produces a reference-step impulse.

Kd × de(t)/dt

02 / OBSERVE

Turn a curve into features.

AWAITING EXTRACTION

The open-loop response is sampled at 1,000 time points. Six features summarize the resulting curve. The last output sample estimates the settled value; rise time, settling time, and onset are measured relative to that estimate.

RISE TIME—

Time between the first 10% and 90% crossings.

SETTLING TIME—

Time of the last sample outside ±2% of the estimated final value.

PEAK OUTPUT—

Largest observed open-loop output.

FINAL VALUE ESTIMATE—

Output at the end of the simulation.

AREA UNDER CURVE—

Integral of output over time, in output × seconds.

ESTIMATED ONSET—

First 1% crossing. Includes the early rise, so it is not the exact dead time.

03 / TUNE

Find gains that meet the objective.

CONSTRAINED NUMERICAL OPTIMIZATION
MINIMIZE TRACKING ERROR

ITAE = ∫0T t |1 − y(t)| dt

ITAE means Integral of Time-weighted Absolute Error. Multiplying error by time penalizes errors that persist. The desired output is 1; T is the simulation duration.
SUBJECT TO

Overshoot ≤ 10%

For a target of 1, the output peak must stay within 1.10.
Kp, Ki ∈ [0.001, 100] · Kd ∈ [0, 50]

Tuning means searching for values of Kp, Ki, and Kd that give a good closed-loop response. The search needs an initial set of gains. Because different starting gains can lead to different results, this method runs up to four separate searches.

  1. Build trial controllers

    A formula based on the plant parameters supplies an initial estimate. Smaller versions of those gains and controllers with Kd = 0 provide additional candidates.

  2. Check the starting gains

    A candidate can start a search only if its closed-loop model is stable and its measured overshoot is at most 9.5%. This leaves a small margin below the final 10% limit. Up to four distinct candidates are chosen.

  3. Improve and compare

    SLSQP, a numerical optimizer, adjusts each candidate’s gains to reduce ITAE while enforcing the constraints. Final controllers are checked again, and the accepted result with the lowest ITAE is kept.

These are local numerical searches: a better solution may exist elsewhere. The gains in the table are the starting values; “Accepted” describes the controller obtained after optimization and validation. This stage generates training targets without using a trained machine-learning model.

04 / COLLECT

A result earns its place in the dataset.

Each final controller is checked again using finer time steps, more precise peak measurements, and longer simulations. Its gains must remain within the allowed bounds, its model must be stable, and overshoot must stay within 10% with numerical tolerance. ITAE must change negligibly as sampling and duration increase. These checks apply to the delay-approximated model, not a guarantee for physical hardware.
